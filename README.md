# CSC 4444 Project: Sudoku Solver and Generator (Backtracking AI)

This project demonstrates a simple AI system that generates and solves 9x9 Sudoku puzzles using the backtracking algorithm. The solver also includes a visual animation of the solving process using Matplotlib.

## Getting Started

You can clone this repository using Git:

```bash
git clone https://github.com/sescob4/CSC-4444-Project.git
cd CSC-4444-Project
```

Or you can download the ZIP file from GitHub:

1. Click the green **Code** button at the top right.
2. Select **Download ZIP**.
3. Extract the folder and open it in your IDE (e.g., VS Code).

## Features

- Generates unique, valid Sudoku puzzles with three difficulty levels: easy, medium, and hard.
- Ensures each generated puzzle has **only one** unique solution.
- Solves any valid Sudoku puzzle using recursive backtracking.
- Animates the solving process step-by-step using Matplotlib.
- Outputs both the full solution and the puzzle to `.txt` files.

## Requirements

Make sure you have **Python 3.6+** installed.

Install required libraries using pip:

```bash
pip install matplotlib numpy
```

No additional datasets are needed.

## File Descriptions

- `board_maker.py` — Generates a Sudoku puzzle and its solution, saves both as `.txt` files.
- `sudoku_solver.py` — Loads a puzzle from a file, solves it using backtracking, and displays the solution as an animation.
- `test.txt` — Example Sudoku puzzle file (generated by `board_maker.py`).
- `test_solution.txt` — Full solution to the above puzzle.

## How to Run

### 1. Generate a Puzzle

Run the following command in your terminal:

```bash
python board_maker.py
```

You will be prompted to:

- Select a difficulty (`easy`, `medium`, or `hard`)
- Enter a filename (e.g., `test`)
- Enter each of these in the console

This will generate two files in the same folder:
- `test.txt` — The incomplete puzzle
- `test_solution.txt` — The fully solved board

### 2. Solve a Puzzle with Animation

Run the following command:

```bash
python sudoku_solver.py
```

You will be prompted to enter the filename of the puzzle you want to solve (e.g., `test.txt`).

- The program will display the solved puzzle in the console.
- An animation window will open, showing the step-by-step solving process using backtracking.
- The total number of solving steps (placements and backtracks) will also be printed in the console.

## Notes

- All inputs and outputs are handled in the console and through text files.
- Make sure that both the puzzle file and its corresponding solution file are in the same directory.
- The animation uses Matplotlib's `FuncAnimation`. Make sure you run it in an environment that supports graphical output (like a local IDE or terminal).
- This project demonstrates AI concepts such as constraint satisfaction, backtracking search, and recursion.
